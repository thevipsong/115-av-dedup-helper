## 📖 项目简介

在 115 网盘长期收藏整理影片时，我们常常面临四大痛点：
1. **多重副本占用大量空间**：同一部影片存在不同清晰度（4K、1080P、720P）、不同压制版本、字幕版（-C）等重复文件；
2. **分集误删风险极大**：传统按名字查重工具往往将 `Part 1 (上集)` 与 `Part 2 (下集)` 误判定为重复文件，误删后追悔莫及；
3. **广告文本与宣传片杂质泛滥**：下载转存时附带了大量的 `.txt`、`.html`、`.nfo` 网址广告或只有十几兆的宣传小视频，手动清理极其繁琐；
4. **大量无用空文件夹残留**：在移动文件、解散目录或删除垃圾后，网盘各处散落着大量没有实际文件的空目录，层级冗余混乱。

**115 番号智能查重与清理助手** 应运而生。它直接运行在 115 网页端，无需提取 Cookie 或配置外部 Python 环境，在浏览器内存中实现**万级文件秒级扫描**、**智能分集隔离保护**、**杂质一键清除**与**空文件夹批量清理**。

## ✨ 核心特性

- 🎯 **深度番号归一化引擎**
  - **有码全覆盖**：精准提取标准片商编号（如 `SSIS-023`、`IPX-754`、`MIDE-001` 等）。
  - **特异前缀适配**：支持 1~4 位数字前缀厂商代号（如 `237nacr`、`259LUXU`、`390JAC`、`348NTR`、`013ONEX`、`4SKMJ` 等）。
  - **特殊格式全兼容**：FC2 全系（`FC2-PPV-1234567`）、无码加勒比/东京热/Heyzo/一本道（`HEYZO-1234`、`CARIB-102412-001` 等）。
  - **智能抗噪过滤**：自动剥离 `489155.com@` 发布站网址水印、压制后缀（`_4k060fps`、`_AI修复`、`-C`、`中文字幕` 等）。
  - **括号深度解析**：完美支持 `[MIDE-360]...`、`(CHO-001)...` 等包裹在括号开头的番号格式。

- 🛡️ **分集独立保护机制 (杜绝误杀上下集)**
  - 深度识别 `4KS1/4KS2`、`CD1/CD2`、`Part1/Part2`、`Disc1/Disc2`、`上集/下集`、`前篇/后篇`、`-A/-B` 等分集标识。
  - **查重标识绑定分集**：`SVVRT-084 [PART1]` 与 `SVVRT-084 [PART2]` 属于不同分集，**绝对不会判定为重复**！
  - 仅在同一个分集存在多个画质版本时才会提示重复，安全度 100%。

- 📁 **空文件夹智能检测与批量清理 (全新上线)**
  - **双重空目录扫描**：不仅能精准识别 0 文件、0 子目录的“直接空目录”，还能穿透递归检测仅包含空子文件夹的“层叠空目录”。
  - **层级路径清晰可辨**：完整展示空目录相对路径，提供 **【📂 打开所在目录】** 直达父级目录核对。
  - **安全批处理**：支持单独快捷删除或一键全选批量移至 115 官方回收站，随时可在回收站还原，零误删风险。

- ⚡ **万级文件极速扫描与防限流节流**
  - 采用 115 官方底层接口（单次拉满 `limit=1150`），1.2 万个文件仅需 11 次网络请求，几秒内即可全部获取。
  - 内置子目录访问安全节流（150ms 缓冲）与自动重试机制，穿透扫描上百个子文件夹亦不会触发 115 防刷限流。

- 🗑️ **非番号杂质文件一键清理工具箱**
  - 自动识别 `.html`（广告网页）、`.txt`（文本广告）、小于 50MB 的推广短视频。
  - 提供 **【⚡ 一键勾选广告小文件 (<50MB)】**，一键批量扫入回收站。

- 🖥️ **现代化 UI 仪表盘与即时搜索**
  - 顶部五维指标卡：即时展示文件总量、番号识别率、真重复组数、可释放冗余空间、空文件夹总数。
  - 即时搜索过滤框：毫秒级响应，任意关键词即时过滤番号、文件名或目录路径。
  - 官方目录直达：提供 **【📂 打开目录】** 按钮，一键在新标签页直达文件具体所在目录，永不 404，原汁原味调用 115 官方原画播放器。

## 🚀 使用教程

1. 打开并登录 [115网盘网页版](https://115.com/)。
2. 鼠标进入任意你需要整理的文件夹。
3. 页面右下角会出现蓝色的 **【🎯 番号查重助手】** 悬浮按钮，点击弹出助手控制面板。
4. 点击 **【🔍 重新扫描】**（若视频存放分散在各子文件夹，可勾选“穿透子文件夹”）：
   - 助手将在数秒内完成全部文件特征比对；
   - 自动在顶部五维仪表盘展示扫描结果与可清理空间。
5. **处理重复文件**：
   - 在 **“⚠️ 重复番号”** 选项卡中，点击 **【⚡ 保留最大 (勾选较小者)】**；
   - 确认无误后点击右下角 **【🗑️ 批量移至回收站】**。
6. **清理广告杂质**：
   - 切换到 **“🗑️ 非番号/杂质文件”** 选项卡；
   - 点击 **【⚡ 勾选广告小文件 (<50MB)】** ➡️ 点击 **【🗑️ 批量移至回收站】** 一键清空。
7. **清理残留空文件夹**：
   - 切换到 **“📁 空文件夹”** 选项卡；
   - 点击 **【⚡ 全选空文件夹】** ➡️ 点击 **【🗑️ 批量移至回收站】** 一键清除无用目录。

> **💡 安全保障**：所有删除操作均调用 115 官方接口移入回收站。如遇误操作，可随时在 115 网页端回收站一键还原。
