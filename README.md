## 📖 项目简介

在 115 网盘长期收藏整理影片与浏览资源社区时，我们常常面临四大痛点：
1. **多重副本占用大量空间**：同一部影片存在不同清晰度（4K、1080P、720P）、不同压制版本、字幕版（-C）等重复文件；
2. **分集误删风险极大**：传统按名字查重工具往往将 `Part 1 (上集)` 与 `Part 2 (下集)` 误判定为重复文件，误删后追悔莫及；
3. **广告文本与宣传片杂质泛滥**：下载转存时附带了大量的 `.txt`、`.html`、`.nfo` 网址广告或只有十几兆的宣传小视频，手动清理极其繁琐；
4. **跨站找片查漏效率低**：逛论坛不知哪些影片网盘里已经收过，手动一个个点开帖子复制链接/磁力极其耗时。

**老司机工作台** 应运而生。它直接运行在浏览器油猴插件中，无需配置外部 Python 环境，打通 **「论坛发现收割 → 115 万级扫描查重 → 归档清理 → 自动检索高清海报」** 完整闭环。

## ✨ 核心特性

- 🧬 **SHA1 二进制同源精准去重 (v5.0 新增)**
  - 直接依据 115 官方返回的 `sha` 与体积进行二进制比对，即便文件已被改成毫无规律的乱码名称，也能 100% 识别出完全相同的重复副本，实现零风险精准去重。

- 📂 **智能建夹与自动归档 (v5.0 新增)**
  - 支持 **按片商/前缀分类**（如 `SSIS-023.mp4` ➔ `/SSIS/`）与 **一影一夹刮削模式**（如 `/SDNM-015/`，完美适配 Emby / Kodi / Infuse），自动复用已有子目录并带走同目录外挂字幕。

- 🏷️ **批量番号规范化重命名 & 自定义模板 & 字幕联动**
  - **自定义命名模板**：在 **【偏好设置】** 支持纯番号 `{code}{part}.{ext}`、字幕/无码标识 `{code}{part}{c}{uc}.{ext}`、完整徽章 `{code}{part} {tags}.{ext}` 及自定义格式。
  - **同目录重名冲突防护**：批处理前预检测同一目录下是否存在同名碰撞，提前安全跳过防止接口报错。
  - **外挂字幕自动保护与同步**：识别并保护 `.srt`/`.ass`/`.ssa` 字幕文件避免被当成杂质误删，并在重命名视频时保留 `.chs`/`.zh` 等语言标识一并同步更名。
  - **防后悔撤销记录**：每次重命名自动保存还原快照（最近 10 批），支持一键批量恢复原名与导出映射表。

- 🔍 **元数据直达 & 缩略图悬浮预览 & 清单查漏 (v5.0 新增)**
  - **外链详情检索**：一键跳转 **JavBus / JavDB / AVSOX** 检索对应番号信息（可在设置中切换偏好站点）。
  - **自动高清海报悬浮预览 (v5.2 增强)**：悬停行内预览图标自动通过跨域代理检索 **JavBus / JavDB / AVSOX** 高清大封面并展示影片标题、发行日期与演员信息（内置防盗链 Blob 下载与 IndexedDB 7 天持久化缓存，可在设置切换“总是自动检索 / 仅缺失时检索 / 关闭”）。
  - **导出与比对查漏**：支持导出 **TXT / CSV（带 BOM 防乱码）/ Markdown** 番号库；支持粘贴外部清单秒速比对网盘“已存在”与“缺失待补”。

- ⏳ **IndexedDB 本地秒开缓存 & 忽略目录名单 (v5.0 新增)**
  - **IndexedDB 大容量缓存**：无 5MB 配额限制，秒开上次扫描成果并标记缓存时间，大幅降低请求频率。
  - **目录忽略过滤**：支持配置关键词或 CID 跳过特定文件夹，避免误扫隐私或精校目录。

- 🎯 **深度番号归一化引擎与分集保护**
  - **有码全覆盖**：精准提取标准片商编号（如 `SSIS-023`、`IPX-754`、`MIDE-001` 等）。
  - **特异前缀适配**：支持 1~4 位数字前缀厂商代号（如 `237nacr`、`259LUXU`、`390JAC`、`348NTR`、`013ONEX`、`4SKMJ` 等）。
  - **特殊格式全兼容**：FC2 全系（`FC2-PPV-1234567`）、无码加勒比/东京热/Heyzo/一本道（`HEYZO-1234`、`CARIB-102412-001` 等）。
  - **智能抗噪过滤**：自动剥离 `489155.com@` 发布站网址水印、压制后缀（`_4k060fps`、`_AI修复`、`-C`、`中文字幕` 等）。
  - **括号深度解析**：完美支持 `[MIDE-360]...`、`(CHO-001)...` 等包裹在括号开头的番号格式。

- 🌐 **98堂 / 色花堂 论坛浏览增强与批量磁力提取 (v5.2 新增)**
  - **批量提取磁力 / ed2k / 附件**：受控并发抓取已选或全部帖子内容，自动提取代码块磁力、Base32/Hex 磁力、`ed2k` 链接，并可联动下载 `.torrent/.zip/.rar/.7z/.txt` 附件，失败帖子会在悬浮窗内集中列出可点链接。
  - **分类快选 + 时间筛选**：列表行首自动插入复选框与顶部快选栏（一天内 / 两天内 / 三天内 / 七天内 / 一个月内），支持全选/清空快速管理。
  - **115 曲库跨站联动 `[115已有]`**：在 `115.com` 扫描后自动将已拥有番号同步至 Tampermonkey 跨站存储；逛论坛时自动为已在网盘里的帖子贴上绿色 **`115已有`** 徽章，支持 **【仅勾未拥有】** 跳过重复收割！

- 🛡️ **分集独立保护机制 (杜绝误杀上下集)**
  - 深度识别 `4KS1/4KS2`、`CD1/CD2`、`Part1/Part2`、`Disc1/Disc2`、`上集/下集`、`前篇/后篇`、`-A/-B` 等分集标识。
  - **查重标识绑定分集**：`SVVRT-084 [PART1]` 与 `SVVRT-084 [PART2]` 属于不同分集，**绝对不会判定为重复**！
  - 仅在同一个分集存在多个画质版本时才会提示重复，安全度 100%。

- 📁 **空文件夹智能检测与批量清理**
  - **双重空目录扫描**：不仅能精准识别 0 文件、0 子目录的“直接空目录”，还能穿透递归检测仅包含空子文件夹的“层叠空目录”。

  - **安全批处理**：支持单独快捷删除或一键全选批量移至 115 官方回收站，随时可在回收站还原，零误删风险。

## 🚀 使用教程

1. 打开并登录 [115网盘网页版](https://115.com/)，进入你需要整理的目录。
2. 点击页面右下角常驻的 **【老司机工作台】** 悬浮按钮打开工作台。
3. **秒开缓存 & 全自动扫描**：
   - 首次进入默认自动开启 **【☑ 包含子目录】** 并启动扫描；再次打开同一目录时自动读取 IndexedDB 本地缓存秒开，如需刷新可点击 **【🔄 重新扫描】**。
4. **重复清理（双引擎查重）**：
   - 在 **“重复番号”** 或 **“同源(SHA1)”** 选项卡中，点击 **【保留最大】** / **【保留最新】**，确认后点击 **【批量移至回收站】**（支持实时进度条与中途停止）。
5. **批量重命名 & 智能归档**：
   - 可先点击顶栏 **【⚙️ 偏好设置】** 选择命名模板（如 `{code}{part}.{ext}` 或保留 `[4K][中字]`）、外链站点与忽略目录名单；
   - 点击 **【✏️ 批量重命名】** 预览无误后一键规范（若改错可在顶栏 **【↩️ 撤销记录】** 一键恢复）；
   - 点击 **【📂 智能归档】** 选择“按片商前缀”或“一影一夹”自动建夹并分类移入（同步带走外挂字幕）。
6. **清单导出与补漏**：
   - 点击顶栏 **【📋 导出 / 对比】** 可一键下载 TXT / CSV / Markdown 清单，或粘贴外界列表快速比对缺失番号。
7. **清理广告杂质与空文件夹**：
   - 在 **“非番号/杂质”** 中点击 **【勾选广告 (<50MB，避开字幕)】** 后移至回收站；在 **“空文件夹”** 中一键清理直接/层叠空目录。

> **💡 安全保障**：脚本内置 `@updateURL` 自动更新机制；所有删除操作均调用 115 官方接口移入回收站，可随时还原。所有写入类操作（删除/改名/建夹/移动）均受 Anti-WAF 节流与熔断机制保护。
