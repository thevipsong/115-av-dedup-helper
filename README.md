## 📖 项目简介

在 115 网盘长期收藏整理影片时，我们常常面临四大痛点：
1. **多重副本占用大量空间**：同一部影片存在不同清晰度（4K、1080P、720P）、不同压制版本、字幕版（-C）等重复文件；
2. **分集误删风险极大**：传统按名字查重工具往往将 `Part 1 (上集)` 与 `Part 2 (下集)` 误判定为重复文件，误删后追悔莫及；
3. **广告文本与宣传片杂质泛滥**：下载转存时附带了大量的 `.txt`、`.html`、`.nfo` 网址广告或只有十几兆的宣传小视频，手动清理极其繁琐；
4. **大量无用空文件夹残留**：在移动文件、解散目录或删除垃圾后，网盘各处散落着大量没有实际文件的空目录，层级冗余混乱。

**115 番号智能查重与清理助手** 应运而生。它直接运行在 115 网页端，无需提取 Cookie 或配置外部 Python 环境，在浏览器内存中实现**万级文件秒级扫描**、**智能分集隔离保护**、**杂质一键清除**与**空文件夹批量清理**。

## ✨ 核心特性

- 🏷️ **批量番号规范化重命名 (v4.5 新增)**
  - **识别番号自动更名**：支持将冗长混乱的文件名（含发布站前缀、压制后缀等杂质）一键统一重命名为标准番号名（如 `sdnm-015_jasna5-unet4_4K__无水印原版勿删.mp4` ➔ `SDNM-015.mp4`）。
  - **智能保留分集与后缀**：完美保留识别到的上下集、分集信息（如 `_PART1.mp4`）以及原视频扩展名（`.mp4`、`.mkv` 等）。
  - **勾选/全量灵活操作**：支持对勾选文件批量重命名，或对当前标签页全量待改名文件一键处理；操作前提供样例差异确认弹窗并内置防风控请求延时。
  - **行内单文件快捷改名**：在列表单项中，对名称尚未规范的文件智能呈现 **【✏️ 改为番号名】** 快捷操作。

- 🎯 **深度番号归一化引擎**
  - **有码全覆盖**：精准提取标准片商编号（如 `SSIS-023`、`IPX-754`、`MIDE-001` 等）。
  - **特异前缀适配**：支持 1~4 位数字前缀厂商代号（如 `237nacr`、`259LUXU`、`390JAC`、`348NTR`、`013ONEX`、`4SKMJ` 等）。
  - **特殊格式全兼容**：FC2 全系（`FC2-PPV-1234567`）、无码加勒比/东京热/Heyzo/一本道（`HEYZO-1234`、`CARIB-102412-001` 等）。
  - **智能抗噪过滤**：自动剥离 `489155.com@` 发布站网址水印、压制后缀（`_4k060fps`、`_AI修复`、`-C`、`中文字幕` 等）。
  - **括号深度解析**：完美支持 `[MIDE-360]...`、`(CHO-001)...` 等包裹在括号开头的番号格式。

- 🛡️ **分集独立保护机制 (杜绝误杀上下集)**
  - 深度识别 `4KS1/4KS2`、`CD1/CD2`、`Part1/Part2`、`Disc1/Disc2`、`上集/下集`、`前篇/后篇`、`-A/-B` 等分集标识。
  - **查重标识绑定分集**：`SVVRT-084 [PART1]` 与 `SVVRT-084 [PART2]` 属于不同分集，**绝对不会判定为重复**！
  - 仅在同一个分集存在多个画质版本时才会提示重复，安全度 100%。

- 📁 **空文件夹智能检测与批量清理**
  - **双重空目录扫描**：不仅能精准识别 0 文件、0 子目录的“直接空目录”，还能穿透递归检测仅包含空子文件夹的“层叠空目录”。
  - **层级路径清晰可辨**：完整展示空目录相对路径，提供 **【📂 打开所在目录】** 直达父级目录核对。
  - **安全批处理**：支持单独快捷删除或一键全选批量移至 115 官方回收站，随时可在回收站还原，零误删风险。

- 🛡️ **全新 Anti-WAF 防风控装甲体系 (v4.4 重磅加固)**
  - **根目录穿透锁定**：当位于网盘根目录（`CID: 0`，总容量数十上百 TB）时，自动禁用全盘穿透递归并弹出显著防护警示，严禁盲目检索数万个子目录，从源头杜绝被 115 官方风控或锁定会话。
  - **官方频控紧急熔断**：深度感知 115 WAF 拦截（状态码 429、验证码页面、`频繁` / `code: 99` 等），一旦触碰立即斩断整个目录遍历队列，绝不盲目重试，绝不连环撞墙；同时完整保留已搜集的文件结果并提醒用户冷却 3~5 分钟。
  - **仿生随机延时与动态冷却**：彻底告别机械固定延时，引入 450~750ms 随机 Jitter 抖动；每穿透 15 个目录自动进入 1.5~2.5 秒“呼吸冷却”状态，深度模拟人类浏览行为。
  - **随时主动安全终止**：扫描过程中提供醒目的 **【🛑 停止扫描 (保留已搜结果)】** 按钮；关闭助手弹窗时自动中断所有后台请求，保护网盘连接状态。
  - **双模速率切换**：支持“🛡️ 安全防封模式 (推荐)”与“⚡ 极速模式”，满足不同文件规模的个性化需求。

## 🚀 使用教程

1. 打开并登录 [115网盘网页版](https://115.com/)。
2. 鼠标进入任意你需要整理的文件夹。
3. 页面右下角会自动常驻蓝色的 **【🎯 番号查重助手】** 悬浮按钮，点击弹出助手控制面板。
4. **全自动智能扫描**：
   - 打开窗口后，默认已自动开启 **【☑ 包含子目录】** 并立即极速检索当前及所有子文件夹；
   - 顶部五维仪表盘实时展示扫描结果与冗余可释放空间；
   - 若只想扫描当前单层目录，取消勾选即可自动重新扫描并记忆偏好。
5. **处理重复文件**：
   - 在 **“重复番号”** 选项卡中，点击 **【保留最大】** 或 **【保留最新】** 一键智能勾选低画质或旧版本副本；
   - 确认无误后点击右下角 **【批量移至回收站】**。
6. **清理广告杂质**：
   - 切换到 **“非番号/杂质”** 选项卡；
   - 点击 **【勾选广告小文件 (<50MB)】** ➡️ 点击 **【批量移至回收站】** 一键清空。
7. **批量清理残留空文件夹**：
   - 切换到 **“空文件夹”** 选项卡；
   - 点击 **【⚡ 全选空文件夹】** ➡️ 点击 **【批量移至回收站】** 一键清除无用层级。

> **💡 安全保障**：所有删除操作均调用 115 官方接口移入回收站。如遇误操作，可随时在 115 网页端回收站一键还原。

- 完善番号识别引擎：支持 `237nacr`、`259LUXU` 等 1~4 位前缀片商。
- 增强括号解析：支持 `[MIDE-360]`、`(CHO-001)` 等括号包裹格式。

### v4.0.0
- 引入现代化极简毛玻璃 UI 仪表盘（总数、识别率、重复数、冗余体积）。
- 新增即时搜索筛选栏，支持毫秒级过滤万条记录。
- 引入清晰度胶囊徽章（`4K`、`60FPS`、`中字`、`无码` 等）。

### v3.1.0
- 新增防限流延时保护（150ms 节流）与自动重试机制，解决穿透扫描时 115 接口抛出 `Unexpected token '<'` 的问题。

### v3.0.0
- 核心重构：引入**分集独立隔离保护**算法（识别 `4KS1/4KS2`、`CD1/CD2` 等），杜绝将上下集当成重复误删。
